# WeCRM Agent (Windows 10)

Системная служба, которая передаёт в WeCRM информацию о компьютере и системе
клиента: ОС, сборка, CPU, ОЗУ, диски, видеокарта, сеть (IP/MAC), серийные
номера и полный список устройств из «Диспетчера устройств».

## Установка

1. Установите [Python 3.9+](https://python.org) (при установке отметьте **Add python.exe to PATH**).
2. Узнайте **ID контакта** (формат `000-000-000`) в карточке клиента
   (CRM → Контакты → карточка → «Основная информация» → «ID для агента»).
3. Запустите **install.bat от имени администратора**, введите адрес сервера
   (по умолчанию `https://welans.cc`) и ID контакта.

Служба `WecrmAgent` устанавливается как системная (LocalSystem):
- запускается автоматически при старте Windows;
- перезапускается автоматически при сбое;
- обычный пользователь не может её остановить или изменить конфигурацию
  (настройки хранятся в `HKLM\SOFTWARE\WeCRM\Agent`).

## Работа агента

- Полный отчёт — при старте службы и далее каждые 5 минут.
- Heartbeat (поддержание статуса «включено») — каждые 60 секунд.
- При первом подключении сервер выдаёт токен; агент сохраняет его в реестр.
- У контакта в CRM (вкладка «Устройства») появляется компьютер
  со статусом **Включено / Выключено** и полной информацией о системе.
- Один ID контакта можно указать на нескольких компьютерах —
  у контакта будет несколько устройств.

## Проверка и отладка

```bat
python agent.py debug     ; одиночный отчёт в консоли (без службы)
```

## Удаление

Запустите **uninstall.bat** от имени администратора.

## Файлы

| Файл | Назначение |
|---|---|
| `agent.py` | код службы (сбор WMI + отправка в CRM) |

| `uninstall.bat` | остановка и удаление службы |
| `requirements.txt` | зависимости Python |
